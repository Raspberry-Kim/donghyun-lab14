# 동현큐 v0.06

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24084894.svg)](https://doi.org/10.5281/zenodo.24084894)

동현랭으로 방식을 정하는 **1인용 선 긋기 땅따먹기** 게임이다. 테두리를 걷다가 안쪽으로 선을 그어 돌아오면 떠도는 **큐**가 없는 쪽이 내 땅이 된다. 테두리를 타고 도는 작은 **슈슈** 얼굴과 멈춘 선을 타고 오는 도화선을 피하며 목표(75%, 욕심쟁이는 90%)를 채우면 다음 단계, 아홉 단계를 마치면 끝.
동현 시리즈의 열네 번째 작은 실험이다. 1981년 오락실 게임 「큐(Qix)」의 구조만 따랐고 그림·소리·색·글·코드는 모두 새로 만들었다.

바로 하기: https://raspberry-kim.github.io/donghyun-lab14/

## 놀이 방법

판은 상아색 프레임 안에 놓인다. 빈 땅은 옅은 격자가 있는 연보라색이고, 점령한 땅에는 안쪽의 밝은 테와 아래 음영이 생긴다. 격자와 프레임은 꾸밈이며 이동과 점령 규칙을 바꾸지 않는다.

- 오른쪽 동현랭 코드의 **출전**을 누르면 코드가 출력한 정수대로 방식·시작 단계·목숨이 정해지고 바로 시작된다.
- 플레이어(노란 마름모)는 80×56칸 판의 **테두리**(내 땅의 경계)를 ←→↑↓로 걷는다. 십자키로 안쪽으로 들어가면 **선**이 그어진다. 속도는 셋: 십자키만 쓰면 **보통**(2프레임에 한 칸), **X를 누른 채**면 **빠르게**(1프레임), **Z를 누른 채**면 **느리게**(4프레임). 걸을 때도 그을 때도 같고, 누르고 떼는 대로 바로 바뀐다. 다시 테두리에 닿으면 선으로 나뉜 두 땅 가운데 큐가 없는 쪽이 점령된다(칸마다 1점). 시작부터 끝까지 Z를 누른 채 그은 **느린 선**은 2점이고 그 땅은 민트색, 보통·빠른 선의 땅은 하늘색으로 칠해진다. 도중에 Z를 떼면 보통 선이 된다.
- **큐**는 파스텔색 선 묶음으로 빈 땅 안을 떠돌며 벽에 튕긴다. 긋는 중인 선에 닿으면 목숨 하나. 테두리 위의 플레이어에게는 닿지 않는다.
- **슈슈**는 작은 슈슈 얼굴로 테두리와 긋는 선을 타고 돈다. 위쪽 테두리 가운데서 나오고 방식마다 정한 간격으로 하나씩 더 온다. 플레이어와 만나면 목숨 하나.
- **도화선**: 선을 긋다가 0.7초(단계가 오르면 더 짧게) 멈춰 있으면 선의 시작점에서 도화선이 붙어 따라온다. 다시 움직이면 그 자리에 멎는다. 플레이어에게 닿으면 목숨 하나.
- 맞으면 긋던 선은 사라지고 플레이어는 선의 시작점으로 돌아가 2초쯤 무적이다. 목표를 채우면 클리어 카드가 뜨고 X 또는 Enter로 다음 단계. 목표를 넘긴 1%마다 100점 보너스.

## 방식 다섯

| 번호 | 방식 | 내용 |
| --- | --- | --- |
| 1 | 기본 | 큐 하나 · 슈슈 둘(15초마다 하나 추가) · 목표 75% |
| 2 | 빌런 떼 | 슈슈 넷에서 시작, 7.5초마다 하나씩 더 온다 |
| 3 | 쌍둥이 큐 | 큐가 둘. 선 하나로 둘을 서로 다른 땅에 갈라놓으면 남은 땅이 다 점령되고 보너스 5,000점과 함께 단계가 끝난다 |
| 4 | 빠른 큐 | 큐 속도 160%, 모양도 더 자주 바꾼다 |
| 5 | 욕심쟁이 | 목표 90% |

단계가 오를수록 큐가 9%씩 빨라지고, 두 단계마다 슈슈 걸음이 빨라지며, 세 단계마다 슈슈가 하나 늘고, 도화선이 붙기까지의 대기가 짧아진다. 규칙 탭의 표에 단계마다의 수가 있다.

## 조작

- 키보드: ←→↑↓ 걷기·선 긋기(선을 긋는 동안은 선의 방향) · X 누른 채 빠르게 · Z 누른 채 느리게 · A 방식 설명 · Enter 메뉴(계속 · 방식 설명 · 저장 · 불러오기 · 포기하고 출전 준비로) · M 효과음.
- 게임패드(닌텐도 배치): A 빠르게 · B 느리게 · Y 설명 · 십자·왼 스틱 이동 · + 메뉴. A와 B가 거꾸로 들어오면 −(Select)로 바꾼다.
- 마우스·손가락 조작은 없다. 화면을 찍어도 플레이어는 움직이지 않는다(결과 카드만 넘긴다).
- 출전한 뒤 판 아래 **전체 화면** 단추를 누르면 게임 화면이 비율을 지키며 화면을 꽉 채운다.

## 저장과 불러오기

- 동현램과 같은 방식이다. Enter(게임패드 +) 메뉴의 **저장**에서 **브라우저 칸 1·2·3** 가운데 하나에 남기거나 **파일로 내려받기**로 `.dhsave` 파일 하나로 내려받는다. 찬 칸은 덮어쓸지 한 번 더 묻는다. 저절로 저장되지는 않는다.
- **불러오기** 메뉴에서 칸을 고르면 그 판이 되살아나고(지금 판은 사라지니 한 번 더 묻는다), **파일에서 불러오기**로 `.dhsave` 파일을 고를 수도 있다. 메뉴가 열린 동안 판은 멎는다. 다른 탭을 보면 저절로 멈춤 메뉴가 뜬다.
- 처음 화면에서는 동현랭 코드 아래 **저장한 판 불러오기**에 칸 세 개가 보인다. 찬 칸을 누르면 바로 이어지고, **지우기**는 두 번 눌러야 비워진다. 칸은 이 기기의 이 브라우저에만 남는다.

## 동현큐 출전 규약

동현랭 코드가 출력한 **정수 셋**이 방식 · 시작 단계 · 목숨이다.

| 자리 | 뜻 | 값 |
| --- | --- | --- |
| 첫째 | 방식 | `1` 기본 · `2` 빌런 떼 · `3` 쌍둥이 큐 · `4` 빠른 큐 · `5` 욕심쟁이. 반드시 있어야 한다 |
| 둘째 | 시작 단계 | `1`~`9`. 없으면 1 |
| 셋째 | 목숨 | `1`~`9`, `0`이면 무한. 없으면 3 |

- 범위를 벗어나거나 정수가 넷 이상이면 시작하지 않고 오류를 알려 준다.
- 예제 여섯: **01 기본**(1), **02 빌런 떼**(2), **03 쌍둥이 큐**(3), **04 빠른 큐**(4), **05 욕심쟁이**(5), **06 기본 · 단계 5 · 목숨 5**(1 5 5).

```
나는 동현이냐?
ㅋㅋ 방식 1 · 기본
뿡뿡 도옹~뿡뿡뿡
동현이구나
```

## 시리즈 연결

[동현랭](https://raspberry-kim.github.io/donghyun-lang/)과 열여덟 실험실을 상단 메뉴로 오간다. [동현테](https://raspberry-kim.github.io/donghyun-lab18/)는 고정 시점의 1인용 단식 테니스다. 데스크톱 메뉴는 동현랭이 두 줄 높이, 나머지는 9열×2줄이다. 모바일은 두 열이며 홀수 개일 때 동현랭만 두 칸 너비를 쓴다.
